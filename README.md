## Featured work

### 🔬 Undergraduate thesis: LLM-generated Bangla misinformation
Showed that the main Bangla fake-news benchmark can be solved from the publisher alone (0.988 macro-F1 without reading the text), then built a 4,667-article test set of Gemini-written paraphrases and fakes at three severity levels. Proposed a confidence-gated fusion of BanglaBERT and a zero-shot Gemini judge; adding the judge raised AUC on out-of-domain fakes from 0.62 to 0.81–0.89. Team of 4, supervised by Dr. Md. Golam Rabiul Alam. The code is private for now because the generated fake articles can't be shared.
`PyTorch` `Hugging Face Transformers` `BanglaBERT` `Gemini API` `scikit-learn`

### 📰 [News Topic Classification](https://github.com/mash-yk/news-topic-classification)
Compared classical and deep learning models for 4-class news classification on 96,646 noisy articles: TF-IDF and Word2Vec across 8 models and a 144-run grid search. Best model (GRU + Word2Vec) reached 92.0% test accuracy and 0.92 macro-F1 (team of 2).
`Python` `TensorFlow/Keras` `scikit-learn` `Gensim` `NLTK`

`React` `Redux Toolkit` `Node.js` `Express` `MongoDB` `JWT`
